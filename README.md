# PCL2 Local Build

A personal, non-commercial local build of the open-source Minecraft launcher
**PCL (Plain Craft Launcher)**, used by a single user to manage Minecraft
instances and mods on one machine.

## Scope

- Uses the public CurseForge API only to search mod / modpack metadata and to
  resolve official download URLs for content the user explicitly selects.
- Does not re-host, mirror, bundle or redistribute any CurseForge content.
- Downloads always use the official CDN URLs returned by the API.
- No public service, no redistribution, no monetization.

## Notes

- Built from the public PCL source; the PCL licence applies.
- This repository only hosts the project description for a CurseForge API
  application. **No binaries or modified builds are distributed here.**
